## 這是什麼

一份**羅馬書全書十六章**的完整研經材料，同時以三種形式提供：

| 形式 | 內容 |
|---|---|
| **網頁 App**（PWA） | 可加到手機主畫面，離線可用 |
| **Word / PDF** | 32 份文件，共 1,668 頁 |
| **Markdown** | 純文字，方便再編輯 |

**三個語言版本：**

| 版本 | 路徑 | 聖經譯本 | 逐節解經 |
|---|---|---|---|
| **繁體中文**（母本） | `/` | 和合本 | 221 段 · 433 節 |
| **简体中文** | [`/sc/`](sc/) | 和合本（简体） | 221 段 · 433 節 |
| **English** | [`/en/`](en/) | World English Bible | 221 blocks · 433 verses |

三個版本的**段落邊界完全一致**，可交叉對照。

**收錄：**

- 羅馬書 **433 節**《和合本》全文
- **221 段**逐節解經（和合本 → 原文 → 直譯 → 關鍵字 → 文法解析 → 經文解釋）
- **16 篇**講章逐字稿（35–40 分鐘，可直接上台）
- **12 條**原文軌跡、**7 組**爭議地圖、全書地形圖
- 小組帶領模式、講台提詞機、講台安全檢查、週間打卡
- **重點畫線＋寫下領受**、**真人語音朗讀**、**AI 陪讀「小智」**

## 快速開始

### 一、開網頁

直接開 `index.html` 就能用（不需要伺服器，不需要網路）。

### 二、發佈到 GitHub Pages

1. 建立一個 repository（例如 `321-bible`），把這裡的檔案全部推上去
2. **Settings → Pages → Source** 選 `Deploy from a branch`，Branch 選 `main` / `(root)`
3. 等一兩分鐘，網址是 `https://<你的帳號>.github.io/321-bible/`
4. 把 README 上方那個連結改成你的網址

```bash
git init
git add .
git commit -m "321聖經講義｜羅馬書"
git branch -M main
git remote add origin https://github.com/<你的帳號>/321-bible.git
git push -u origin main
```

### 三、加到手機主畫面

| 裝置 | 步驟 |
|---|---|
| **iPhone / iPad** | Safari 開啟網址 → 分享鍵 → **加入主畫面** |
| **Android** | Chrome 開啟網址 → 選單 → **安裝應用程式** |

裝好之後**沒有網址列**，看起來就像一般的 App；**第一次開啟後即可離線使用**。

## 三個貼身的功能

### ✍️ 畫線與領受

讀經文時**點一下**那一節就畫線，**再點一下**寫下領受。
解經的每一段也可以畫線。全部收在「我的 → 我的畫線與領受」，可匯出成 Markdown。

### 🔊 真人語音

朗讀鍵用的是真人語音（雲帆／曉辰／雲哲三種聲音可選）。
**長按朗讀鍵**可以切換聲音與語速。
聽過的段落會存在裝置上，第二次聽不必再連線，**離線也聽得到**。

若語音服務連不上，會自動退回裝置內建的語音，不會卡住。

### ✨ 小智

右下角的星星鍵。小智知道你正在讀哪一章，會**緊扣本章的材料**回答。

畫線寫完領受後，可以直接按「**問小智**」，把那句經文與你的領受一起帶過去。

小智有四條羅馬書專屬的規矩：

1. **經文優先** —— 先回到羅馬書本文；羅馬書沒處理的，明說
2. **原文誠實** —— 分清「可查證的事實」與「一種可能的理解」
3. **爭議不裁決** —— 七類爭議一律先講「兩邊都同意的」
4. **講台責任** —— 若你要拿去講道，提醒哪些需要加平衡句

> 小智每次都會說：**我不是聖靈，也不能代替你的牧者。**

## 這份材料刻意遵守的原則

**一、解經的次序不可顛倒**

> 原文 → 文法 → 句法 → 上下文 → 歷史背景 → 作者原意
> → 聖經神學 → 基督與福音 → 321生命應用 → 今日實踐 → 講章

不可先決定要講什麼，再回頭到聖經找支持。

**二、爭議並陳，不作裁決**

七組主要爭議（羅七章的「我」、預定與揀選、以色列全家得救、順服掌權者的界線、可爭議之事、非比與猶尼亞、守日）
一律先給「**兩邊都同意的**」，再列立場與根據，最後給一句可以在台上說的話。

> **App 的爭議卡，永遠不會出現「正確答案」四個字。**

**三、講台誠信分級**

每一則原文材料都標明：

| 級別 | 意思 |
|---|---|
| 🟢 **可上台** | 同字、同字根、原文語態——可查證的硬事實 |
| 🟡 **需加平衡句** | 學者有不同理解，必須說明 |
| 🔴 **不可上台** | 缺乏可靠依據（例如「羅馬人把屍體綁在犯人身上」） |

> **鐵律：不確定就不要用。**

**四、修正條款（每章固定）**

> **若有一天你在聖經裡看見與本課不同的亮光，**
> **請跟隨聖經，不要跟隨我們。**
>
> 聖經是準則。321 是工具。工具永遠服在準則之下。

**五、App 刻意不做的事**

- ❌ 連續打卡天數／斷簽提醒 —— 那會製造律法主義的焦慮，而羅馬書整卷書在拆這個
- ❌ 排行榜、學習積分競賽 —— 「我比他多讀」正是羅2與羅14在對付的
- ❌ 「你今天還沒讀經」的推播 —— 那是定罪的語氣
- ❌ 社群動態牆、廣告、內購解鎖經文

小組長只看得到組員「**做了／沒做**」，**看不到內容**。筆記與掙扎只留在自己的裝置上。

## 外部服務

App 本身沒有伺服器，但兩個功能會連線：

| 功能 | 端點 | 說明 |
|---|---|---|
| **小智 AI** | `xiaozhi-proxy.spch321.workers.dev` | Cloudflare Worker 代理，API 金鑰放在 Worker，**不在前端** |
| **真人語音** | `azure-tts.spch321.workers.dev` | Azure TTS 代理，回傳音訊後存在裝置本機 |

**兩者都是選用的**：關掉真人語音會改用裝置內建語音；不點小智就完全不會連線。
其餘所有內容（經文、解經、講章）都在 `index.html` 裡，**離線完全可用**。

> 要換成自己的 Worker，改 `index.html` 裡的 `SVC` 常數即可。

## 隱私

**這個 App 沒有伺服器。**

你的筆記、**畫線與領受**、進度、打卡紀錄，全部存在**你自己的裝置**（瀏覽器的 localStorage）。
沒有帳號、沒有追蹤、沒有分析工具、不上傳任何東西。

「我的 → 匯出我的資料」可以隨時把它們存成 JSON 檔自己保管。
