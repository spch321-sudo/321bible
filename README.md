## 全書的三個結構性標記

```
【第一個「但如今」】3:21
  1:18–3:20  每一張嘴被封住（最低點一）
     ↓
  3:21「但如今，神的義……已經顯明出來」

【第二個「如今」】8:1
  7:24「我真是苦啊」（最低點二）
     ↓
  8:1「如今，那些在基督耶穌裡的就不定罪了」

【那個「所以」】12:1
  1–11章 教義 →【頌讚】11:33–36
     ↓
  12:1「所以……將身體獻上，當作活祭」
```

## 全書的首尾呼應

| 開頭 | 結尾 |
|---|---|
| 1:5「叫人……**信服真道**」 | 16:26「使他們**信服真道**」 |
| 1:11「使你們可以**堅固**」 | 16:25「**惟有神能**……堅固你們的心」 |
| 1:2「藉眾先知在聖經上所應許的」 | 16:26「藉眾先知的書指示」 |
