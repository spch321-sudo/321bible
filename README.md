## 這是什麼

羅馬書全書十六章的完整研經材料，做成一個可以離線使用的網頁 App。

一節一節從希臘文原文讀起，附上字義、文法、句法的說明，再帶到神學重點、基督中心的讀法，最後是可以直接上台的講章逐字稿與生命應用。

三種語言，同一份內容，在 App 裡隨時切換。

| | 繁體中文 | 简体中文 | English |
|---|---|---|---|
| 檔案 | `index.html` | `sc.html` | `en.html` |
| 聖經版本 | 和合本 | 和合本 | World English Bible |

## 每一個解經段的六層

| 層 | 內容 |
|---|---|
| **和合本經文** | 該段的經文 |
| **希臘原文** | 公有領域校勘本 |
| **直譯** | 盡量貼著原文語序，看見中譯背後的結構 |
| **關鍵字** | 原文｜音譯｜Strong's｜字根｜基本字義｜本節語境 |
| **文法解析** | 時態、語態、語氣、格位，並說明「這對理解本節有什麼影響」 |
| **經文解釋** | 整合字義、文法、上下文與背景，並區分「經文明說的」與「可合理推論的」 |

---

## 解經上的幾個堅持

**分清楚哪些是經文說的，哪些是推論。** 每一段解經都會分開寫「經文本身明確表達的」與「可以合理推論的」。

**有爭議的地方並陳，不說死。** 主要立場與各自的經文根據都列出來，說明哪一種內證較強，但不宣稱唯一答案。

**明確標出不可以那樣講的地方。** 常見的斷章取義、過度靈意化、忽略歷史背景的讀法，都直接標示出來並說明理由。

## 部署到 GitHub Pages

這個專案不需要任何建置環境，推上去就能用。

**一、建立倉庫並推送**

```bash
git init
git add .
git commit -m "321聖經講義－羅馬書"
git branch -M main
git remote add origin https://github.com/<你的帳號>/<倉庫名>.git
git push -u origin main
```

**二、開啟 Pages**

倉庫頁面 → **Settings** → **Pages** → Source 選 **Deploy from a branch** → 分支選 `main`、資料夾選 `/ (root)` → Save。

等一兩分鐘，網址會長這樣：

```
https://<你的帳號>.github.io/<倉庫名>/
```

**三、（選用）自動部署**

倉庫裡已附 `.github/workflows/pages.yml`。若想改用 GitHub Actions 部署，在 Settings → Pages 把 Source 改成 **GitHub Actions** 即可，之後每次 push 都會自動更新。

## 安裝成手機 App

網站開啟後可以裝到桌面，之後離線也能讀。

- **iPhone / iPad**：Safari 開啟 → 分享鈕 → 加入主畫面
- **Android**：Chrome 開啟 → 選單 → 安裝應用程式
- **電腦**：Chrome / Edge 網址列右側的安裝圖示

裝好之後，主畫面上會顯示：

| 版本 | 主畫面名稱 |
|---|---|
| 繁體中文 | **羅馬書講義** |
| 简体中文 | **罗马书讲义** |
| English | **Romans Study** |

App 內部的標題仍是「321羅馬書講義」，只有主畫面圖示下方的名字縮短了——手機主畫面的字數有限，太長會被截斷。

第一次連線後，Service Worker 會把三個語言版本與圖示都快取起來，之後完全離線可用。

## 檔案結構

```
index.html      繁體中文
sc.html         简体中文
en.html         English
icon-512.png    App 圖示（512×512）
sw.js           Service Worker（離線快取）
.nojekyll       告訴 GitHub Pages 不要跑 Jekyll
```

三個 HTML 各自是完整的單檔 App——樣式、程式、內容、180 與 192 的圖示全部內嵌，不依賴任何外部資源。512 的圖示因為檔案較大，獨立放成 `icon-512.png`，給 Android 安裝與啟動畫面用。

### 換圖示或改名稱

**圖示**　180 與 192 以 base64 內嵌在三個 HTML 的 `<head>` 裡，512 是根目錄的 `icon-512.png`。

> 換圖時請注意：**四角要滿版，不要留白邊。** iOS 與 Android 會自己套一次圓角遮罩，原圖若已經有圓角，白色的角會露出來變成白邊。

**名稱**　主畫面顯示的名字在三個地方，各檔案都要改：

```html
<meta name="apple-mobile-web-app-title" content="羅馬書講義">
<meta name="application-name" content="羅馬書講義">
```

```js
short_name: "羅馬書講義",
```

**改完記得動 `sw.js` 的版本號**，否則已經裝過的使用者會繼續看到舊快取：

```js
const VERSION = 'v3.4.0-...';   // 改成新的
```

## 關於 321

國度321空中團契的核心理念：

**三個基礎**　耶穌是我的榜樣／聖經是我的準則／聖靈是我的引導
**兩個核心**　讓耶穌作王／讓耶穌得著一切的榮耀
**一個目的**　建立屬神的體系

321 服在聖經權威之下。解經的次序始終是：原文 → 文法 → 上下文 → 作者原意 → 聖經神學 → 基督與福音 → 生命應用，不倒過來。若某項理念與該章沒有直接關係，就不勉強加入。
